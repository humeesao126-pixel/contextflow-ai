
# ✦ ContextFlow AI
### Your AI Assistant with Smart Conversation Memory

**ContextFlow AI** is a conversational AI chatbot built using
Python, Streamlit, Google Gemini API, and SQLite.

Unlike a basic chatbot that processes each message independently,
ContextFlow AI maintains conversation context using session-based
memory and a configurable sliding-window mechanism.

The application also provides local chat storage, conversation
management, a memory inspector, response streaming, and an
interactive user interface.

## 📖 Project Overview

Large Language Models (LLMs) are generally stateless when accessed
through APIs. This means that previous conversation messages must
be supplied again when requesting context-aware responses.

ContextFlow AI addresses this problem by maintaining conversation
history and including recent messages in requests to Gemini.

The project demonstrates:

- LLM API integration
- Conversational context management
- Session-based memory
- Sliding-window memory optimization
- Persistent conversation storage
- Interactive AI application development

## ✨ Key Features

### 🤖 1. Gemini AI Integration

- Integrated Google Gemini using the official Google GenAI SDK.
- Generates AI-powered responses using conversation context.
- Supports streaming responses for a more interactive experience.
- Includes API error handling and retry logic.

### 🧠 2. Conversation Memory

- Stores active conversations using Streamlit Session State.
- Maintains conversation history during a live session.
- Includes recent messages when generating AI responses.
- Allows users to configure the context window.

### 🔄 3. Sliding-Window Memory

A configurable memory window limits the amount of conversation
history sent to Gemini.

Users can adjust the memory window from 2 to 20 turns.

This helps manage context size while preserving recent
conversation information.

### 💾 4. SQLite Conversation Storage

- Stores conversations and messages in a local SQLite database.
- Maintains separate conversation records.
- Supports loading saved chat messages.
- Saves completed user-assistant exchanges.

### 💬 5. Multiple Conversation Management

Users can:

- Create new conversations
- Switch between conversations
- Rename existing conversations
- Delete conversations
- View saved messages

### 🔍 6. Memory Inspector

The Memory Inspector provides information about:

- Total messages
- User messages
- AI responses
- Messages included in the active memory window
- Current conversation memory

This helps users understand how conversational memory works.

### 📥 7. Export Chat History

Users can download their conversation history as a TXT file.

This makes it easier to save, review, or share conversations.

### 🧪 8. Offline Demo Mode

ContextFlow AI includes an Offline Demo Mode that allows users
to explore and demonstrate the application without consuming
Gemini API requests.

Demo Mode:

- Generates predefined simulated responses
- Supports interface testing
- Helps demonstrate chat management
- Works without calling the Gemini API

**Note:** Demo Mode responses are simulated and are not
generated by Gemini.

### 🎨 9. Cloud Lilac Studio Interface

The application includes a custom Streamlit interface featuring:

- Soft lavender color palette
- Interactive welcome screen
- Suggested prompt buttons
- Sidebar navigation
- Styled chat messages
- Conversation management controls
- Developer footer

## ⚙️ How ContextFlow AI Works

The application follows this general workflow:

1. The user enters a message through the Streamlit interface.
2. The message is added to the active conversation.
3. The memory system selects recent conversation history based
   on the configured sliding window.
4. In Online Mode, the conversation context is sent to Gemini.
5. Gemini generates a response, which can be displayed through
   streaming.
6. The completed conversation exchange is saved locally using
   SQLite.
7. The user can continue chatting, inspect memory, switch chats,
   or export conversation history.

In Offline Demo Mode, the Gemini request is replaced with a
predefined simulated response.

### Memory Architecture

**Session Memory**

Streamlit Session State maintains the messages associated with
the active conversation.

**Sliding-Window Memory**

The application limits the context sent to Gemini to recent
conversation turns.

**Persistent Storage**

SQLite stores conversation records and messages locally.

Persistent database storage and browser-session access are
different: saved records may not automatically appear in a
completely new browser session.

## 🚀 Installation and Setup

### Prerequisites

Before running the application, ensure you have:

- Python installed
- Git installed
- An internet connection for Gemini Online Mode
- A valid Gemini API key for Online Mode

### Step 1: Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/humeesao126-pixel/contextflow-ai.git
cd contextflow-ai
```

### Step 2: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate the virtual environment.

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

### Step 3: Install Dependencies

```bash
python -m pip install -r requirements.txt
```

The main dependencies are:

```text
streamlit
google-genai
```

SQLite is included with standard Python installations and
does not require a separate Python package.

### Step 4: Configure Your Gemini API Key

Create the following file inside the project directory:

```text
.streamlit/secrets.toml
```

Add your Gemini API key:

```toml
GEMINI_API_KEY = "YOUR_ACTUAL_GEMINI_API_KEY"
```

Replace the placeholder with your own API key.

**Security Notice:**

Never publish your real API key or commit `secrets.toml` to
GitHub. The project `.gitignore` excludes this file.

### Step 5: Run the Application

In the project terminal, run:

```bash
python -m streamlit run app.py
```

Once Streamlit starts, open:

http://localhost:8501

The application will open in your web browser.

**Important:** This localhost address works only while the
Streamlit application is running on your computer.

## 🧭 How to Use the Application

### Start a Conversation

1. Launch the application.
2. Create or select a conversation.
3. Enter a message in the chat input.
4. View the generated response.

### Adjust Conversation Memory

1. Open the sidebar.
2. Find the Memory Window slider.
3. Select the number of conversation turns to retain in the
   active context window.

### Inspect Memory

1. Expand the Memory Inspector in the sidebar.
2. View the conversation metrics.
3. Display the current conversation memory.

### Manage Conversations

Use the sidebar to create, select, rename, or delete chats.

### Export a Conversation

1. Select a conversation containing messages.
2. Find the Export Conversation section.
3. Click the download button.
4. Save the generated TXT file.

### Use Offline Demo Mode

1. Enable Offline Demo Mode from the sidebar.
2. Enter a message or select a suggested prompt.
3. View the simulated response.

Demo Mode does not require a Gemini API request.

## ⚠️ Known Limitations

- Gemini API access is subject to quotas and rate limits.
- An internet connection is required for Online Mode.
- SQLite stores data locally.
- Browser sessions do not guarantee access to all previous
  conversation records after session expiration.
- The application is not configured for public multi-user
  deployment.
- Offline Demo Mode generates simulated responses.
- Conversation recall depends on the selected memory window.
